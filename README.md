A one-line crypto trading joke for make.fun's "Laugh Track: The
Crypto Trading Joke Contest": a trader sets a stop-loss, moves it
down twice, deletes it, then blames the market — turns out his risk
management is just grief with extra steps.

`main.py` (pure Python standard library) writes the joke to
`/output/entry.txt` — one line, 140 characters, valid UTF-8.

## Run it

```sh
python3 main.py
```
